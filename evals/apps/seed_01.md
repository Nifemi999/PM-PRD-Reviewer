# Feature: Dark Mode for Mobile App

## Problem
Users complain about the app being too bright at night. We need to fix this because it hurts their eyes.

## Goals
We want to improve user satisfaction and make the app easier to use at night.

## Scope
We will build a dark mode theme for the iOS and Android apps. 
We will also update the settings screen so users can toggle it on and off.

## Non-Goals
We won't build a custom color picker for users. 
We won't build dark mode for the web app right now.

## Requirements
- Add a toggle in Settings.
- When toggled, the app changes to dark colors.
- Ensure the app is fast when switching themes.

## Risks
- Some third-party libraries might not support dark mode.
